# Me to You &nbsp; 💌

The Me to You Project is a space where anyone can post your favourite quotes or read quotes posted by other individuals. I began this project in May 2026 hoping to bring some whimsy and positivity back onto the internet which seems to have turned into a place of so much hatred and has just lost its overall spark compared to how it was back then.

The minimalist artwork and animations were done hoping to make the experience much more special than just reading quotes off a blog post. I hope this project can bring joy to those who need it.

What began as a simple project to learn JavaScript out of my coursework turned into my first passion project.

### For ♡
People who would like to share their favourite quotes with the hopes of uplifting others or people who need to hear words of encouragement and motivation. 

### Stack
* JavaScript
* HTML
* CSS
* Supabase
* Vite

### My Learnings
* Frontend-only implementation facilitated through Supabase with PostgreSQL,
* Implementing animations through original illustrations through JavaScript,
* Actions triggering sound-effects

##### This project is currently not deployed although I intend to in the near future (aka still figuring it out)
